# 已确认需求

## 目标与验收范围

- 第一阶段以个人使用为验收目标。
- 复刻本机已安装的 Contexts 3.9.0 的 UI 和交互风格。
- 优先支持当前 Apple Silicon Mac 和当前 macOS。

## 窗口侧栏（用户称应用栏/Dock）

- 每个显示器均显示窗口侧栏。
- 侧栏展示所有窗口；点击窗口行直接激活该窗口，不使用“每应用一个图标再悬浮展开”的交互。
- 窗口行采用紧凑的单行图标和窗口标题，不显示应用名副行；应用栏窗口行高与图标同为 24px，相邻条目的垂直间距为 0。无标题的有效窗口回退显示应用名；原始窗口标题仍用于身份匹配。
- 统一过滤输入辅助等临时窗口；无标题且无文档的窗口需具备普通任务窗口能力，不能仅凭标准窗口类型收录，也不能按应用名一律排除正常未命名窗口。
- OpenContexts 设置窗口打开时纳入应用栏和切换器，关闭后移除；自身侧栏与切换面板不纳入。
- 不支持固定应用，也不显示纯菜单栏或后台应用。
- 无窗口的应用不显示侧栏条目。
- 窗口独立管理：同一应用的窗口可分属不同分组，并分别拖拽排序；它们不要求在侧栏中相邻。
- 新窗口默认进入“未分组”。用户可手动创建并命名分组；空分组始终显示。
- 分组可拖拽排序；删除分组时，其窗口移动到“未分组”。
- 跨重启保存全部分组及窗口期望的分组、顺序。重新出现的窗口按应用、文档 URL 或标题（如可用）匹配；仅无歧义匹配时恢复，否则进入“未分组”。运行中标题变化不触发重新分组。
- 侧栏支持配置为始终显示或悬浮显示。全屏时始终收起至屏幕边缘并可悬浮唤出，覆盖“始终显示”设置。
- 设置中仅可选择左、右位置并保存，均为纵向栏；收起和悬浮唤出沿对应边缘进行。旧版上、下位置回退为右侧。
- 侧栏高度随当前窗口条目、分组标题和操作区的实际内容收缩，默认沿屏幕边缘垂直居中；内容超过屏幕可用高度时封顶并滚动，不拉伸填满屏幕。

## 窗口切换

- 切换粒度为单个窗口，而非应用。
- 切换器采用浅蓝色背景，窗口行只显示图标和标题，行高紧贴图标高度。
- 窗口列表按最近使用（MRU）顺序排列，并包含最小化和隐藏窗口。
- 接管 Command-Tab：按 Tab 前进，按 Shift-Tab 后退，松开 Command 激活选中窗口。
- Escape 取消；Up/Down 也可选择窗口。
- 被选中的最小化或隐藏窗口应恢复并激活。
- 切换器包含其他桌面空间和全屏应用的窗口。
- 可配置的快捷键仅用于“所有窗口”和“当前应用窗口”；不提供侧栏开关快捷键。
- 在每个显示器中心同时显示窗口切换器，所有屏幕使用相同的窗口列表和选择状态。

## 验收

| 场景 | 预期 |
| --- | --- |
| 同应用窗口 | 可分属不同分组并独立排序 |
| 窗口关闭／应用无窗口 | 窗口条目不可见；空分组仍显示 |
| 重开窗口 | 唯一匹配时恢复；歧义时进入“未分组”；标题变化不重新分组 |
| 快捷键 | Tab 前进、Shift-Tab 后退、Up/Down 选择、Escape 取消；支持所有窗口和当前应用窗口 |
| 多显示器 | 每屏中心同步显示相同列表和选择状态 |
| 全屏 | 仍包含全屏窗口；侧栏收起至边缘并悬浮唤出 |
| 参考 UI | 仍待实际捕获 Contexts 3.9.0 参考界面，尚未验证 |

产品行为与整体方案已获用户最终确认。技术验证仍包括跨空间／全屏切换、Command-Tab 拦截与权限失败回退。工程验收要求：未获得辅助功能权限或应用退出时不得拦截 Command-Tab。

## 技术选型

- 采用 Swift + AppKit；设置界面使用 SwiftUI。
