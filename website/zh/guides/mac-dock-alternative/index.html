Mac Dock 与侧边栏指南

Mac Dock 替代方案：用侧边栏切换与分组窗口

当多个窗口共用 Dock 中的一个应用图标时，找到具体窗口往往还要多一步。Open Contexts 把打开的窗口逐个列在侧边栏或底部应用栏里，显示标题、应用图标和保存的分组。这篇指南介绍这种方式适合哪些工作习惯、如何设置，以及它与 macOS Dock 各自承担的用途。

为什么需要用于窗口切换的 Dock 替代方案？

同一应用打开多个窗口时，macOS Dock 仍然只显示一个应用图标。你可以从应用的 Dock 菜单选择窗口，而一个可见的窗口列表能让你先读到标题，再直接点击目标。

  • 逐个查看窗口，同一个应用的多个窗口也有各自的条目。
  • 点击想去的窗口，或用 ⌘Tab 从键盘切换。
  • 按任务把不同应用的窗口整理进命名分组。

选择 Mac 窗口侧边栏或底部窗口 Dock

Open Contexts 支持多显示器：Dock 栏可以放在每个显示器的左侧、右侧或底部，窗口切换器也可在多个显示器上使用。侧边栏纵向列出窗口标题；底部栏把同一批窗口排成一行。两种布局都用于访问已经打开的窗口。

希望列表始终在视线内，可以选择常驻显示；希望需要时再出现，可以选择悬浮显示，在指针靠近屏幕边缘时展开。显示内容可选仅应用图标，或同时显示窗口标题与 Dock 角标。

空间不足时，底部应用栏会均匀收缩条目。

按任务整理侧边栏里的窗口

准备发布时，可以把编辑器、终端和问题跟踪页面放进一个分组；查资料时，可以把浏览器与笔记窗口放在一起。点击 ＋ 新建分组，把窗口拖进去，再拖动窗口或分组标题调整顺序。

右键点击窗口并选择“固定”，可以在列表自动更新时保留它的位置。分组名称和排序保存在本地；重启 Open Contexts 后，能够匹配的窗口会回到保存的分组位置。

保存分组整理的是窗口列表。它不会重新打开已经关闭的应用、恢复桌面窗口的尺寸和位置，也不会把窗口移到另一个 macOS Space。

窗口侧边栏适合哪些工作习惯？

  • 同一应用有多个窗口：通过标题区分浏览器用户配置、文档或终端会话。
  • 鼠标与键盘交替使用：用鼠标点击栏里的窗口，双手在键盘上时再用 ⌘Tab。
  • 按任务组织工作：把代码、沟通、资料窗口放进自己命名和排序的分组。

如果主要需求是打开应用，很少选择同一应用的不同窗口，系统 Dock 可能已经够用。如果你更关注键盘操作，可以先读Mac 窗口切换指南。

与 macOS Dock 配合使用

Open Contexts 提供另一种访问已打开窗口的方式。启动应用、文件栈与废纸篓等用途仍由系统 Dock 承担。Open Contexts 不会修改或隐藏系统 Dock；是否隐藏它，可以按个人习惯在系统设置中选择。

应用重点是选择窗口和保存分组，目前不提供实时窗口预览、窗口搜索、触控板切换手势、窗口吸附或自动平铺。保存分组整理的是列表，并非桌面布局。

想比较侧边栏与搜索的区别，可以阅读 Open Contexts 与 Contexts 对比，或查看窗口切换器比较。

设置你的 Mac 窗口侧边栏

  1. 从 GitHub Releases 下载 Universal DMG。Open Contexts 面向 macOS 13 Ventura 及以上版本。
  2. 打开 DMG，把 OpenContexts.app 拖到“应用程序”目录并启动。应用会常驻菜单栏。
  3. 点击菜单栏图标，选择授予辅助功能权限，在“系统设置 → 隐私与安全性 → 辅助功能”中启用 Open Contexts。如果窗口栏未显示内容，请退出并重新启动应用。
  4. 从菜单栏图标打开设置，选择左侧、右侧或底部位置，再选择常驻或悬浮显示，以及图标与标题的显示方式。
  5. 点击 ＋ 创建第一个分组，拖入相关窗口，再点击窗口标题把它调到最前。

安装说明包含 macOS 打开限制和权限排查步骤。全屏行为仍需要更多真实环境验证，请检查自己依赖的工作方式。

常见问题

这是免费的 Mac Dock 替代软件吗？

Open Contexts 基于 Apache 2.0 免费开源，无需账号、订阅或试用期限。它提供用于选择已打开窗口的 Dock 替代方式，不覆盖系统 Dock 的所有功能。

侧边栏能放到右侧或底部吗？

可以。从菜单栏图标打开设置，选择左侧、右侧或底部，还可以选择一直显示，或在指针靠近边缘时再出现。

它能替代名为 Sidebar 的付费应用吗？

Open Contexts 与 Sidebar 是独立产品。这篇指南中的“侧边栏”指 Open Contexts 的纵向窗口列表，不表示它复现了另一款软件的全部功能。

重启后窗口分组还在吗？

分组名称和排序保存在本地，能够匹配的窗口也会恢复所属分组和列表顺序。已经关闭的应用不会被重新打开，桌面布局也不会被恢复。

给打开的窗口一个固定去处

试试左右侧边栏或底部窗口栏，为一个任务创建分组，看看按标题选窗口是否符合你的习惯。
