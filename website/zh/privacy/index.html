隐私政策

本政策适用于 Open Contexts macOS 应用及其官方网站。应用的窗口数据保存在你的 Mac 上；官网使用的第三方服务会在下文说明。

适用范围与项目

Open Contexts 是由 zshnb 及贡献者维护的免费开源项目。本政策说明当前应用及 opencontexts.zshnb.com 的数据处理方式，不适用于独立运营的衍生版本或第三方网站。

Mac 上的本地数据

应用无需账户，未内置使用行为统计。它通过 macOS 辅助功能权限识别、激活窗口及处理窗口切换快捷键，并读取应用标识、窗口标题、可获取的文档地址及窗口状态，以显示和恢复窗口分组。

分组名称、应用标识、窗口标题、可获取的文档地址、排列顺序和固定位置保存在本地文件 ~/Library/Application Support/OpenContexts/groups.json 中。显示方式、语言和快捷键设置保存在 macOS 偏好设置中。Open Contexts 不会上传窗口及分组数据。

窗口标题及文档地址可能包含敏感信息。能够访问你的 Mac 或备份的人可能读取该文件。

下载与更新检查

应用使用 Sparkle 检查 GitHub 上的更新并下载发布版本。检查或下载时，会向 GitHub 及其分发基础设施发送网络请求，对方可能接收你的 IP 地址及请求元数据。请求不包含窗口标题、文档地址或分组数据。分发版本默认关闭自动更新检查；你主动检查或通过更新器启用自动检查后，可能发生这些请求。

GitHub 按其 隐私声明 处理相关请求。

官网统计与服务提供方

官网使用 Google Analytics 4 了解访问情况并改进页面。它可能收集页面浏览、来源、站外链接点击等交互、浏览器及设备信息、大致位置和 Cookie 标识。详情见 Google Analytics 数据保护说明 和 Google 隐私政策。

Cloudflare 托管并分发网站，可能为内容交付及安全处理 IP 地址和技术请求数据，详见其 隐私政策。网站从 Google Fonts 加载字体，因此浏览器会向 Google 服务器发送请求，详见 Google Fonts 常见问题。这些服务可能在你所在国家或地区以外处理信息。

官网统计无法访问你 Mac 上的窗口标题、文档地址或保存的分组。

Cookie、保留时间与控制方式

Google Analytics 使用包括 _ga 在内的第一方 Cookie 区分访问。网站还会在浏览器本地存储中保存浅色或深色主题偏好。详情见 Google Cookie 说明。

你可以在浏览器中阻止或清除 Cookie 和本地存储、拦截统计请求，或使用 Google Analytics 停用浏览器插件。仅清除 Cookie 不会阻止后续统计请求。

本地应用数据会保留到你将其删除。要重置分组，请先退出应用，再删除 groups.json；这不会清除 macOS 偏好设置或备份。你可以在 macOS 系统设置中撤销辅助功能权限。卸载应用可能仍会留下已保存的数据。

网站统计的保留时间取决于统计配置；基础设施及支持记录按各服务提供方的保留政策处理。对于第三方控制的记录，我们不承诺固定的删除期限。

信息共享与反馈

我们不出售你的个人信息。上述服务提供方会处理托管、统计、字体、下载及更新所需的信息。提交问题或其他反馈时，我们会收到你主动分享的信息，用于回复及维护项目。GitHub 问题公开可见，请勿填写私密窗口标题、文档路径、凭据或其他敏感信息。

联系与政策更新

如有隐私问题，或希望就你曾向项目提供的信息提出请求，请先通过 GitHub 问题追踪器 联系维护者，首次留言不包含敏感信息，以安排适当的后续沟通。根据当地法律，你可能享有访问、更正或删除信息的权利。我们无法读取仅保存在你 Mac 上的应用数据。

政策变更会发布在本页，并更新上方日期。另请参阅 服务条款。
