为每一个窗口而生的
Mac 窗口切换器。

Open Contexts 是一款免费、开源的 macOS 窗口管理器。⌘Tab 按最近使用顺序在单个窗口之间跳转，就像 Windows 上的 Alt-Tab；屏幕边缘的应用栏让每个打开的窗口都一键可达。100% 原生 Swift，没有 Electron，无需账号。

每一个窗口，
一个 ⌘Tab。

系统自带的 ⌘Tab 每个应用只显示一个图标。Open Contexts 显示每一个窗口，两个 Chrome 窗口就是两个选项。列表按最近使用排序，刚刚用过的窗口永远只差一次按键。

⌘Tab 所有窗口 ⌘` 当前应用的窗口 ⇧Tab 或 ↑ 后退 Esc 取消 松开 ⌘ 即切换

所有打开的窗口，
始终一目了然。

应用栏停靠在屏幕边缘，按标题列出每个窗口，并显示应用图标和 Dock 角标。点击任意一行即可把窗口调到最前，即使它已最小化或隐藏。

会记住的
窗口分组。

Contexts 从未支持保存分组，Open Contexts 支持。把窗口按代码、聊天或资料分组，重启之后依然各归其位。

  • 直接在应用栏中新建、重命名和删除分组
  • 拖动窗口或整个分组来调整顺序
  • 固定窗口，让它在列表更新时保持原位
  • 重启后自动恢复窗口在分组中的位置

把应用栏放在
最顺手的位置。

左侧、右侧或底部，由你决定。可以常驻显示，也可以在指针碰到屏幕边缘时再出现。可以只显示图标，也可以同时显示图标和窗口标题。

  • 左、右或底部边缘，在每块屏幕上居中
  • 始终显示，或悬浮显示
  • 仅图标，或图标和窗口标题
  • 底部栏会均匀收缩条目，所有窗口都放在一行
  • 支持英语、西班牙语、法语、日语和中文界面

常见问题

Open Contexts 免费吗？

是的。Open Contexts 基于 Apache License 2.0 免费开源，包含全部功能，没有试用期、账号或订阅。

Open Contexts 是 Mac 上的 Alt-Tab 吗？

是的。Windows 上的 Alt-Tab 在窗口之间切换，而 macOS 的 ⌘Tab 在应用之间切换。Open Contexts 接管 ⌘Tab，按最近使用顺序列出每一个窗口；⌘` 只列出当前应用的窗口。

Open Contexts 和 Contexts 有什么区别？

Open Contexts 是付费应用 Contexts 中应用栏和窗口切换器的开源复刻，并新增了 Contexts 不支持的自定义分组保存。Contexts 的 Search、Fast Search 和触控板手势暂未复刻。 查看 Open Contexts、AltTab、Contexts 与 macOS ⌘Tab 的完整对比 →

和 AltTab 等其他窗口切换器相比有什么不同？

Open Contexts 用紧凑的列表显示每个窗口的应用名、图标和标题，而不是缩略图网格；同时搭配常驻的应用栏，可以把窗口整理进保存的分组。 查看 Open Contexts、AltTab、Contexts 与 macOS ⌘Tab 的完整对比 →

支持哪些 Mac 和 macOS 版本？

需要 macOS 13 Ventura 或更高版本，以 DMG 形式提供。

为什么需要辅助功能权限？

辅助功能权限让 Open Contexts 能够发现和切换窗口，并处理键盘快捷键。未授权或应用未运行时，Open Contexts 不会接管 ⌘Tab。

我的窗口分组保存在哪里？

分组和窗口位置保存在本地的 ~/Library/Application Support/OpenContexts/groups.json，不会上传。
