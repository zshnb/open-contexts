Mac 窗口切换器与 Dock 怎么选？

比较 Open Contexts、AltTab、Contexts、Sidebar、uBar、DockDoor 与 macOS 原生切换，按窗口切换、项目分组或 Dock 用途来选择。DockDoor 免费版与独立 Pro 分别介绍。

按任务整理

Open Contexts

如果你需要紧凑的窗口列表、常驻应用栏，以及重启后仍然保留的自定义窗口分组，可以选择它。

AltTab

如果窗口缩略图能帮你更快找到目标，可以选择它。免费版包含触控板手势，Pro 增加搜索与更多显示样式。

Contexts 3

使用系统原生

macOS ⌘Tab

如果在应用之间切换就够用了，保留系统原生方式即可。用 ⌘` 切换当前应用的窗口，无需安装。

查看 Apple 快捷键说明 →
替换完整 Dock

Sidebar

需要启动器、窗口标题、预览、搜索和吸附等 Dock 功能，可以考虑 Sidebar。Stacks 用来组织应用和文件夹。

使用完整任务栏

uBar

需要任务栏、收藏项、多行入口或每屏独立栏，可以考虑 uBar。它的窗口合并按同一应用组织。

查看 uBar 对比 →

保留 macOS 原生 Dock，增加窗口预览、搜索切换器和 Glance。免费、GPL-3.0 开源。

窗口各就各位，
切换一键可达。

Open Contexts 把窗口切换与你一天的工作安排连在一起。

常驻应用栏

在屏幕边缘保留窗口标题，点击即可切换。也可以让应用栏在鼠标到达边缘时才出现。

记住你的分组

为代码、研究或聊天创建分组，把窗口拖到合适的位置；重启后，自定义分组仍然保留。

紧凑的窗口列表

⌘Tab 按最近使用顺序显示每个窗口的应用名、图标与标题，⌘` 则只列出当前应用的窗口。

查看窗口切换器与应用栏的演示 →

哪些场景，
其他选择更适合。

Open Contexts 目前没有窗口搜索、实时缩略图与触控板手势。窗口预览可以比较 AltTab、Sidebar 与 DockDoor；搜索可以比较 Contexts、AltTab Pro、Sidebar 与 DockDoor。需要完整任务栏可以看 uBar，需要替代 Dock 的档案与组件可以看 DockDoor Pro。

如果你主要在应用之间切换，系统原生快捷键可能已经够用。Open Contexts 需要 macOS 13 或更高版本，以及用于发现和聚焦窗口的辅助功能权限。
