DockDoor 评测：免费版与 DockDoor Pro 的区别

评估 DockDoor 需要分开看两款产品：给原生 Dock 增加窗口预览的免费开源应用，以及独立付费、提供档案和组件的 DockDoor Pro 替代 Dock。

本文由 Open Contexts 项目方根据官方资料整理，属于资料评测，未进行竞品实测或性能基准测试。

DockDoor 免费版：给现有 Dock 增加预览

免费版在 Dock 应用上方显示实时窗口缩略图，也支持标题列表形式的预览，并提供可搜索的窗口切换器。Glance 可以在标准 Command-Tab 界面上方显示选中应用的窗口。

它主要是在熟悉的操作方式上增加辨认和选择窗口的入口：保留 macOS 原生 Dock。DockDoor 免费版以 GPL-3.0 开源，不需要付费解锁功能，最低要求为 macOS 13。

DockDoor Pro：独立的替代 Dock

Pro 提供自己的 Dock，并增加包含应用、文件夹和组件的档案。AppSense 可以根据当前应用切换档案；其他功能包括每屏 Dock、固定应用/文件/链接、文件托盘，以及预览中的窗口平铺操作。

Pro 一次性 $20，可用于最多三台 Mac，需要 macOS 14.6 或更新系统。官方提供 14 天退款保障，这不等于无需付款的免费试用。免费版的 GPL 许可证也不能直接套用到 Pro 应用的源码或许可证上。

两款产品都要检查的要求

两款产品均公布支持 Intel 和 Apple Silicon，并为窗口功能申请辅助功能与屏幕录制权限。最低系统不同：免费版为 macOS 13，Pro 为 macOS 14.6。

在目标机器核对权限，为 Pro 付款前查看当前购买条款。比较时不要用免费版的价格对应仅 Pro 提供的替代 Dock 档案等功能。

免费版和 Pro 分别检查什么

  • 免费版：同一应用有多个窗口时，缩略图或标题列表能否帮你辨认目标窗口？输入搜索是否符合你的键盘习惯？
  • Pro：切换当前应用时，档案和 AppSense 是否显示你需要的 Dock 入口？组件和每屏 Dock 在常用屏幕上是否有帮助？
  • 两者：在自己的环境检查最小化窗口、Space、外接显示器和权限处理。

这些是建议的体验检查问题。本页没有实测结果、资源占用数据或已验证的兼容性矩阵。

保存窗口分组的工具适合什么位置

希望保留原生 Dock，用预览和搜索辨认窗口，可以考虑 DockDoor 免费版；希望使用可配置的替代 Dock，可以考虑 Pro。

Open Contexts 主要提供标题列表和跨应用的选定窗口分组，目前没有实时预览和搜索。如果目标是重复使用一个项目的窗口集合，而不是改变 Dock 的内容，这个区别比笼统的“最佳 Dock 应用”更有帮助。
