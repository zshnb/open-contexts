uBar 评测：Mac 任务栏模式、窗口合并与试用

uBar 适合想在 macOS 上使用可配置 Dock 或任务栏的人。决定是否需要它，应该先看模式、窗口合并和显示器设置如何配合自己的工作，再判断简洁的窗口侧边栏是否足够。

本文由 Open Contexts 项目方根据官方资料整理，属于资料评测，未进行竞品实测或性能基准测试。

Dock 与任务栏模式会改变操作方式

uBar 文档描述的任务栏默认设置包括显示窗口标题、使用 Automatic Window Grouping，以及点击合并入口后打开窗口列表。Dock 模式则默认始终按应用合并，不显示应用标题和时钟。

所以模式选择本身就是评估的一部分。如果目的是找到某个具体文档窗口，可以从任务栏模式开始，再比较 Never 与 Automatic 两种合并设置。

布局、收藏项和多显示器

uBar 可以放在屏幕任意一边，使用最多五行入口，并收藏应用、文件和文件夹。官方还介绍了每屏独立或镜像任务栏、悬停预览和活动指标。

在你最小的显示器上检查多一条常驻栏之后是否仍有足够工作空间。行数和窗口标签会用屏幕面积换取更多可见入口，哪一种合适取决于你的窗口数量。

系统、权限与许可证

官方公布的最低系统为 macOS 10.13。辅助功能权限用于窗口控制；文档也说明了相关 macOS 版本中窗口标题、新窗口处理和预览需要屏幕录制权限。

14 天试用可以用来检查这些设置。Personal 一次性 $30，最多两台 Mac；Commercial 为每位员工一次性 $50，同样最多两台 Mac。根据使用方式选择许可证，工作用途不要直接套用个人版价格。

试用期间检查什么

  1. 为同一应用打开多个窗口，比较任务栏与 Dock 模式，再比较 Never 和 Automatic 合并。
  2. 在实际工作中使用文件或文件夹收藏项和悬停预览。
  3. 接上常用显示器，检查各屏任务栏的位置与剩余工作空间。
  4. 切换 Space、最小化窗口、重新连接显示器后，再检查窗口入口。
  5. 在目标 macOS 版本核对权限与兼容性。

这些是建议的检查步骤，并不是 uBar 实测结果。

uBar 与 Open Contexts 分别适合什么需求

想使用可配置的完整任务栏，可以评估 uBar；缺少的是由自己挑选、跨越多个应用的保存窗口分组，可以评估 Open Contexts。

uBar 的 Window Grouping 按所属应用组织窗口，Open Contexts 的保存分组按你挑选的工作集合组织。本页资料评测没有得出性能优胜者，也没有验证所有 Space 和全屏场景。
